I build products end to end: the schema, the API, and the interface people actually touch. My default is **TypeScript + React** on the client, **Node.js + PostgreSQL** on the server, and **Solidity** whenever a piece of the system needs to be verifiable instead of trusted.

These days I'm building **[Quantara](https://github.com/Nicco6598/Quantara_2026)**, a local-first desktop suite for construction project management, with Web3 work continuing on the side.

### Selected work

**[Quantara 2026](https://github.com/Nicco6598/Quantara_2026)** · `Tauri 2` `React 19` `Rust` `SQLite`
Local-first desktop application for Italian construction projects: SAL workflows, price lists, materials, accounting, documents and an operational audit trail. Everything runs on the machine — no server round-trip, source-available under a proprietary licence.

**[Exora](https://github.com/Nicco6598/Exora)** · `React` `Solidity` `Bittensor` · [live](https://exoramarkets.vercel.app/)
Prediction markets with an AI subnet layer, deployed across Ethereum, Polygon, Arbitrum, Base and Optimism, wrapped in a liquid-glass interface.

**[sillage](https://github.com/Nicco6598/sillage)** · `Next.js` `PostgreSQL` `Gemini` · [live](https://sillage-gamma.vercel.app)
Perfumery platform for discovering and curating scents: search by notes, brands and accords, community reviews, AI-assisted moderation.

**[bombyx-menu](https://github.com/Nicco6598/bombyx-menu)** · `Next.js` `Tailwind` `Zustand` · [live](https://bombyx-menu.vercel.app/)
Digital menu for an Art Deco cocktail bar in Milan — client work, designed and shipped end to end.
